# glass-ui-style

A [Claude Code](https://claude.com/claude-code) skill for building web pages in an Apple-inspired glass style:
glassmorphism, a deep-space dark mode with a light mode, an electric-cyan accent, spring animations and fluid typography.

The skill gives Claude a complete design system to follow — CSS tokens, a page skeleton, core components
(header, cards, buttons, badges, lists, schedule grid), entrance animations, vanilla-JS patterns,
an accessibility checklist and a list of don'ts.

## Install

```bash
git clone https://github.com/Nerdyone-1234/glass-ui-style ~/.claude/skills/glass-ui-style
```

Or copy `SKILL.md` into `~/.claude/skills/glass-ui-style/` (for one project: `.claude/skills/glass-ui-style/`).

## Use

Ask Claude for a page "in the glass UI style", or run `/glass-ui-style`.

## Notes

- Not affiliated with or endorsed by Apple. "Apple-inspired" only describes the look.
- The fonts use the system font stack (SF Pro on Apple devices, Segoe UI Variable on Windows, then `system-ui`).
